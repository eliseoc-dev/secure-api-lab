# Secure API Lab

Defensive cybersecurity project focused on building, reviewing and hardening a REST API.

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- pytest
- HTTPX
- Git
- GitHub

## Project Goals

The project demonstrates:

- API security fundamentals
- Authentication
- Authorization
- Password hashing
- JWT
- Input validation
- Rate limiting
- Secure error handling
- Security headers
- Secrets management
- Security testing
- OWASP-inspired defensive practices

## Important

The intentionally vulnerable version of this project is designed only for local educational testing and should not be deployed publicly.
